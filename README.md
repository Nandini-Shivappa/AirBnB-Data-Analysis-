
#  Airbnb Data Analysis

This project presents an in-depth exploratory data analysis (EDA) of Airbnb listings, aimed at uncovering patterns and insights about pricing, availability, location, and property types. The analysis is performed using Python and Jupyter Notebook, leveraging libraries such as Pandas, Seaborn, and Matplotlib.

##  Objective

The primary goals of this Airbnb data analysis project are to:

- Understand key features affecting Airbnb pricing
- Identify high-demand and high-revenue property types
- Analyze availability and seasonal trends
- Explore host behavior and listing patterns
- Provide actionable insights for hosts, customers, and business stakeholders

##  Files

- `AirBnb_data_analysis.ipynb`: Jupyter Notebook containing the full exploratory analysis, data cleaning steps, visualizations, and insights.

##  Key Insights

- Neighborhoods with the highest and lowest average prices
- Correlation between price and number of reviews
- Most common property types and their occupancy patterns
- Distribution of listings by room type, location, and availability
- Seasonal fluctuations in availability and pricing

##  Tools & Technologies

- **Python 3**
- **Jupyter Notebook**
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical operations
- **Matplotlib & Seaborn** – Data visualization
- **Plotly (optional)** – Interactive charts

##  Visualizations

The analysis includes various charts and plots:
- Bar charts and pie charts for categorical analysis
- Heatmaps for correlation analysis
- Distribution plots for price and availability
- Time series plots for trends over months
